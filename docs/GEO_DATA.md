# GeoSite без тяжёлой базы

Полный `geosite.dat` RUNET Freedom сейчас весит десятки мегабайт. На компактных
MikroTik его не следует держать в постоянной памяти без внешнего накопителя.

Панель использует малые категории из проекта RUNET Freedom — например
`youtube.txt`, `discord.txt` и `google.txt` — и скачивает их через уже
подключённый VLESS/SOCKS. Выбранная категория разворачивается в реальные
домены и записывается в маршрут Xray.

`ru-blocked.txt` также можно подключить в будущей версии, но он заметно больше
и должен быть включён пользователем явно.
