# Безопасность

Панель предназначена для локальной сети. Установщик публикует веб-интерфейс
только на указанном LAN bridge и создаёт отдельного пользователя RouterOS API
для панели.

Не пробрасывайте порт панели в интернет. Не публикуйте VLESS-ссылки, резервные
копии RouterOS или файл `panel-v2-state.json`: в нём может находиться VLESS URI.

Если нужно отозвать доступ, удалите пользователя `unblock-api`, контейнеры и
правила с комментарием `MikrotikVPN`.
