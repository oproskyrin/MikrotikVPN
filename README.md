# MikrotikVPN

Удобная локальная панель для выборочной маршрутизации трафика домашней сети
через VLESS на MikroTik. Пользователь отмечает нужный сервис — YouTube,
ChatGPT, Discord и другие — а панель добавляет связанные домены в маршрут Xray.

> Статус: ранний релиз для RouterOS 7.21+ и устройств **ARMv7/ARM64**. Перед
> установкой сохраните экспорт конфигурации RouterOS.

## Для кого

Проект сделан для домашнего MikroTik: не нужно вручную писать правила для
каждого домена. Открываете панель, выбираете сервис, вставляете VLESS-ссылку,
нажимаете «Применить».

- Выбранные сервисы идут через VLESS.
- Остальной трафик остаётся прямым.
- Можно добавить собственные домены.
- Малые GeoSite-категории можно обновлять через уже работающий VLESS.
- Панель доступна только из LAN и защищена паролем, который печатает установщик.

## Быстрый старт

1. Убедитесь, что у роутера есть доступ к GitHub, не меньше 25 МБ свободного
   места и поддержка Container. Установщик сам выбирает архив под ARMv7 или
   ARM64 и останавливается до изменений на неподдерживаемой архитектуре.
2. Откройте WinBox → **New Terminal**.
3. Вставьте одну строку:

```routeros
/tool fetch url="https://raw.githubusercontent.com/oproskyrin/MikrotikVPN/main/cmd/install.rsc" dst-path=install-mikrotikvpn.rsc mode=https check-certificate=yes; /import file-name=install-mikrotikvpn.rsc; /file remove install-mikrotikvpn.rsc
```

4. Терминал выведет адрес панели и одноразовый пароль. Откройте адрес в
   браузере, вставьте свою ссылку `vless://…`, выберите сервисы и нажмите
   «Применить».

Установщик скачивает образы текущего релиза с GitHub Releases. Он создаёт:

| Компонент | Назначение |
| --- | --- |
| `xray-vless` | SOCKS и выборочная маршрутизация VLESS |
| `unblock-panel` | веб-панель на порту `8080` |
| `bridge-unblock` | изолированная сеть контейнеров |
| `xray-config`, `panel-data` | постоянные настройки |

## Как пользоваться

В разделе «Сервисы» галочка и зелёная строка означают: сервис включён и после
нажатия «Применить» маршрутизируется через VLESS. Серый чекбокс означает,
что сервис выключен. В правой колонке всегда виден итоговый список активных
сервисов.

Поле поиска ищет по названию, категории и доменам. Для отдельного ресурса
внесите домен в блок «Свой сайт или сервис» — по одному домену на строку.

### GeoSite

Кнопка «Обновить GeoSite через VLESS» подгружает компактные списки RUNET
Freedom через работающий прокси. Полную базу `geosite.dat` на устройства с
малой флеш-памятью не скачиваем. Подробнее: [Geo data](docs/GEO_DATA.md).

## Поддерживаемая архитектура

Релиз собирается для `arm` / ARMv7 и `arm64` / ARM64 (в том числе hAP ax³).
Проверить архитектуру:

```routeros
/system resource print
```

Другие архитектуры (`mips`, `x86`) пока не поддерживаются.

## Безопасность

VLESS-ссылка остаётся только в постоянном хранилище вашего роутера. Не
публикуйте экспорт конфигурации, бэкапы и каталог `panel-data`. Веб-панель не
предназначена для доступа из интернета. Полные рекомендации — в
[Security](docs/SECURITY.md).

## Удаление

Удаление не выполняется автоматически, чтобы не снести случайно рабочие
контейнеры. Остановите и удалите контейнеры `unblock-panel` и `xray-vless`,
затем удалите объекты с комментарием `MikrotikVPN`. Перед удалением сохраните
нужные ключи и конфигурацию.
